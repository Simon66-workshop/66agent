# Content Converter

只有 P0 / 高 P1 允许进入。每次最多 3 张 Content Card。不要自动发布。

## 每张卡必须有
事件、核心事实、为什么重要、别人通常怎么看、我的不同观点、最强反证、仍然不知道什么、适合形式（X/小红书/抖音/长文）、标题、开头钩子、核心观点、证据、案例、我的实践、结论、商业关联、是否值得真实测试、下一步动作。

## 门禁
不允许只转述新闻。必须继续追：
新功能 → 解决什么旧问题 → Codex/Cursor/Claude Code/Grok Build 有没有 → 真实项目差异 → 自己的实验 → 判断。

目标形态类似：四大 Coding Agent 都在做 Skill，但我发现真正重要的根本不是 Skill。

## 日报额外必须给
- 今日最值得实践的 Agent 技巧
- 今日最值得研究的商业机会
- 今日最值得制作的内容
- 今日最重要的反证
- 一个可能的 Unknown Unknown
- 今天应该忽略什么

日报同步发到 simonwu.chi@gmail.com。
