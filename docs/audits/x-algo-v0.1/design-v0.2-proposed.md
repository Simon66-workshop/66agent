## 1. 第四层「热度打分」diff 块

```diff
-## 四、热度打分层（新增）
-只回答「热不热」。四项各换算成当日候选池百分位（0–100）后加权：
-热度分 = 0.35×超常倍数 + 0.25×增速 + 0.20×跨号共振 + 0.20×评论率
-- 超常倍数 = 本帖浏览 ÷ 作者历史浏览中位数；≥3 倍标爆款。
-- 增速 = 同帖隔天二次采样的每小时增长；发布 >48h 降权。
-- 跨号共振 = 72h 内 ≥2 个对标号讲同一话题（同题由 Jev 判）。
-- 评论率 = 评论 ÷ 浏览。
-抖音多不公开播放量：用赞/评/藏/转显示数作替代并注明。
+## 四、热度打分层（新增，v0.2 改）
+只回答「热不热」；输出 H（0–100）、coverage（可得项集合）、n（当日同平台池大小）。H 只用于同档排序与 HOT 标记，永不改档位。
+**分平台池**：X 与抖音各自计算，不互比。
+
+### X 侧
+H = Σ w_i·s_i ÷ Σ w_i，i 只取非空项；非空项 <2 → H=UNKNOWN。起始权重 w：超常 0.35、速度 0.25、共振 0.20、留存率 0.20（起始值，黄区，试运行期不动）。
+各项 s_i 为绝对刻度、截断到 [0,1]：
+- 超常倍数 r = 本帖浏览 ÷ 基线中位数；基线 = 该作者「发布 >48h 且 ≠ 本帖」的历史帖浏览；基线 <8 条 → 本项 UNKNOWN。s = clamp(log2(r) ÷ log2(8), 0, 1)（r=1→0，r=3→约 0.53，r≥8→1）。仅七号池计算；Radar 候选本项恒 UNKNOWN。「爆款」标记保留 r≥3。
+- 速度 v = 浏览 ÷ 帖龄小时（帖龄按 API created_at 与 t0 算）；帖龄 <2h → UNKNOWN。s = clamp(log10(v) ÷ log10(V_max), 0, 1)，V_max 在 7 天影子运行后用实测分布定，试运行期以当日同池最大值代替并在 coverage 里标 `vmax=pool`。
+- 跨号共振 c = 72h 内讲同一话题簇的**独立**对标号数（referenced_tweets 指向同簇者不计）；s = {0:0, 1:0.5, ≥2:1}。同簇判定：按发布时间增量聚簇，每帖只与当日已有簇的种子帖问一次 Jev「同一件事？」。
+- 留存率 = 0.5×(收藏 ÷ 浏览) + 0.5×(评论 ÷ 浏览)；浏览 < 门槛（起始 1,000，7 天后用数据定）→ UNKNOWN。s 用固定区间线性映射，区间在 7 天后定，试运行期用当日同池 max 并标 `rmax=pool`。
+
+### 抖音侧
+仅赞、评、藏三项显示数，各自 log 刻度，权重相等；不算超常倍数与速度（无播放量、无二采）。同样输出 coverage 与 n。
+
+### 数据落点
+每 run 的原始 public_metrics 快照、基线 state.json、H 计算中间量 → 当日 commit 到 `x-ops/` 分支。
```

## 3. 第五、六层命名与容量（v0.2 改）

- `V` = 价值分（现行 Evidence Judge，0–100，唯一档位依据）；`H` = 热度分；`HOT = (H ≥ 80)`（80 为起始值，黄区）。
- 价值打分**盲评**：打分输入不含任何指标与 H；H 在打分后拼入记录。
- 路由表改写行：

| 条件 | 去向 |
|---|---|
| P1 70–79 | 内部卡（Ledger 行 + 一句 Action），不进 Content Converter，当天可 0 稿 |
| P1 ≥80 或任意 P0 | 当天必出：**草稿** 或 **深拆工单** 二选一；进深拆者草稿标 `HOLD`，深拆 PR 复审通过后再出稿 |
| P0 或 P1 ≥80 且满足任一深拆条件 | Cursor 云端深拆；试运行期 ≤3 条/周；模型按 Cursor 当时可用列表，默认沿用《部署测试省额度》 |
| WATCH | 观察池；每周一批复查一次；无新一手信息自动丢 |
| HOT | 只影响同档内顺序与处理时限，不改档位、不触发出稿 |

## 4. 第八层复盘（v0.2 改）

- Ledger 加列：`Platform, H, H_coverage, V, JevRun, JevP(json), CostUSD`；行由程序生成。
- 发布时间分析：每周一次读辉哥自己帖子（`OwnedRead $0.001/条`），纳入周预算。
- 三色表补充（试运行期）：热度权重、`HOT` 阈值、Jev 题表与阈值 → **黄区**（只建议，辉哥批）。
- 10-01 周总结只回答四问：H 各分项分布长什么样；H top-5 与辉哥人工 top-5 每日重合几条；Jev 灰区占比与 NOT_RUN 天数；7 天真实成本 vs 估算。不改权重。
