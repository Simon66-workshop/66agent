## 二、规则过滤层（现行，纯程序）
- 时间窗：>60 天最多 WATCH，除非有新一手增量；相对时间（如「2天前」）核不出绝对时刻不算窗内。
- 去重：同 thread / 同作者同事件只留原帖；不收转发。

## 四、热度打分层（新增）
只回答「热不热」。四项各换算成当日候选池百分位（0–100）后加权：
热度分 = 0.35×超常倍数 + 0.25×增速 + 0.20×跨号共振 + 0.20×评论率
- 超常倍数 = 本帖浏览 ÷ 作者历史浏览中位数；≥3 倍标爆款。
- 增速 = 同帖隔天二次采样的每小时增长；发布 >48h 降权。
- 跨号共振 = 72h 内 ≥2 个对标号讲同一话题（同题由 Jev 判）。
- 评论率 = 评论 ÷ 浏览。
抖音多不公开播放量：用赞/评/藏/转显示数作替代并注明。

## 五、价值打分层（现行 Evidence Judge）
满分 100：项目相关 25、证据强度 25、可执行性 20、商业价值 20、新颖/非对称信息 10。≥85 P0；70–84 P1；55–69 WATCH；<55 DISCARD。必须拆 FACT/INFERENCE/ASSUMPTION/UNKNOWN 并回答「什么现实证据能证明这条错」。点赞高、工具新、自称 MRR、无来源截图、纯跑分不算事实。
新增合并规则：档位只由价值分决定；热度分不能拉入 P0，只用于同档排序和加急；热度 ≥80 的 P0/P1 当天处理。每天最多交 P0 2 条、P1 3 条。

## 七、Cursor 深拆标准
输入包：原帖链接与快照、各层打分记录、3–5 个具体问题、66agent 对应规则文件。
七步：1 追最原始一手来源；2 能复现就复现、关键数字逐个核对；3 四家横比；4 至少 2 条反证（或说明找过没找到）；5 写适用条件；6 列 FACT/INFERENCE/ASSUMPTION/UNKNOWN，每条事实附链接；7 给 66Workshop 设计可迁移小实验（成本/时长/成功标准）并重评档位。
