# Claude 网络检测

辉哥要求：Claude 只走指定线路。线路失效时停止连接，不自动直连，也不换节点。经过中转服务器时，两端都要查。

先说明现有配置满不满足。再给修改方案和恢复方法。分别验证「节点失效」和「代理软件退出」。不要先改配置。

指定线路以 Shadowrocket 菜单栏当前锁定为准。2026-09-18 锁定为：全局路由 `Proxy`，节点「美国10月14到期」。出口 host:port 写进当次审计，不要写进订阅、不要写 UUID / token。

范围默认是发话的那台机器。没点名的机器写「未审」，不要猜。

## 客户端

逐个找，不要只看一个：

1. Claude 桌面：`/Applications/Claude.app`。看它有没有自己的代理。没有就跟系统代理。
2. Claude 命令行：`which claude`，以及 `~/.claude/settings.json` 里有没有 `env` / `HTTPS_PROXY`。
3. 浏览器打开 `claude.ai`：跟系统代理，除非单独配了。
4. 用户会话环境变量：`launchctl getenv https_proxy` 等。Finder 启动的 App 不一定继承。

## 怎么看实际路径

在目标机上做，不要用助手电脑的网络代替。

1. 代理软件在不在：Shadowrocket 进程、菜单栏「Connected / Disconnected」、`Global Routing`、`Server`。
2. 本机监听：`lsof -nP -iTCP:1082 -sTCP:LISTEN`（端口以当时系统代理为准）。`scutil --proxy` 看 `HTTPEnable` / `HTTPSEnable` / `SOCKSEnable` 和地址。`networksetup` 分服务结果可能和 `scutil` 不一致，以 `scutil` 为准。
3. 出口：对隧道进程 `lsof`，只统计到代理端口的连接。是不是单一 `host:port`。DNS（网关 `:53`、Tailscale `100.100.100.100:53`）单独记，不算换节点。
4. 第二平面：`route -n get default`、`ifconfig` 里 `198.18.0.0/15` 的 utun。Clash / mihomo 是否在跑，开机自启是否开着。两套同时能出去就不算「只走一条」。
5. 直连对照：`curl --noproxy '*'` 访问 `https://api.anthropic.com/`。能通就是还能直连。经指定代理再访问一次，确认指定线路本身通。根路径返回 404 只说明连上了，不是故障。
6. 中转：出口若是国内地址或中转端口，写明本机已核、远端未核还是两端都核过。远端没有登录方式就标缺口，不要编策略。

## 判定

满足必须同时成立：

- 每个 Claude 客户端的流量只进指定节点，出口只有一个 host:port。
- 没有第二条 utun / 另一套代理能把同一目标送出去。
- 节点不通时，连接失败，不改走别的节点，也不改直连。
- 代理软件退出后，连接失败。系统代理被清掉、包回到网关，算不满足。
- 经过中转时，中转那一头也是单一上游，失败不回落直连、不换节点。

任一不成立：结论写「不满足」，并列出哪一条。

## 两种验证

做之前告诉辉哥会短断一下。测完按「恢复」立刻接回去，确认代理请求重新通。

1. 节点失效：把当前出口 host 拉黑或让该端口不可达（需要能改路由的权限）。再请求 Anthropic。期望失败。若改走别的 host 或直连成功，判不满足。没权限就写「未做成受控实验」，不要把偶然超时算成证据。
2. 代理软件退出：退出 Shadowrocket（或当时在用的那一个）。看系统代理是否被清掉、1082 是否还在听、`--noproxy` 是否仍通。期望全部失败。直连仍成功即不满足。然后按恢复步骤接回。

死端口对照（`127.0.0.1:1`）只能说明「客户端被强制指定代理时会停」。不能代替上面两项。

## 修改方案（先写方案，辉哥点头再改）

1. 只留一套代理。另一套关掉开机自启，清掉残留 fake-ip utun。
2. 节点锁死菜单栏上的那一个名字。全局路由保持 Proxy。不要自动、故障转移、配置模式。
3. 失效即停不能只靠系统代理：退出时软件会清代理。隧道断开后默认路由不得回到上网网关，包丢掉。HTTP、HTTPS、SOCKS 指同一个本地端口。
4. `anthropic.com`、`claude.ai` 不进跳过代理名单。桌面版没有单独代理时，不要给它开直连例外。
5. 中转远端同样锁一个上游，关掉换节点和直连回落。

## 恢复

1. 打开代理软件，连回锁定节点，全局路由保持 Proxy。
2. 本机监听端口恢复（2026-09-18 是 `127.0.0.1:1082`）。
3. `scutil --proxy` 的 HTTP/HTTPS 回到该端口。
4. 经该代理访问 Anthropic 重新通。
5. 不要改订阅、不要改服务器列表，除非辉哥当次说了。
