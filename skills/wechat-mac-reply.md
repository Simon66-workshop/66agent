# 微信 Mac 代回（MacBook Pro）

在辉哥 MacBook Pro 的微信桌面版上：读会话、起草回复、经核对后发送。无官方微信 MCP/插件；靠本机 GUI + 截图核对。

## 可行性结论（审计）

- **路径 A（辉哥先点开目标会话 → 助手只核对标题、起草、确认后发送）可行**，应作为默认。
- **路径 B（助手自己搜/点进会话）半可行、高风险**：Mac 微信 AX 树几乎为空，搜一搜易抢焦点，坐标点击易点错；未用截图验标题前禁止发送。
- 本机常见拦路：侧栏 `machineId` 串到 Mini/Air、自动化权限 `-25208`、本机 Python/xcrun 损坏导致外部 OCR 脚本不可用。读屏以 **截图 + CopyToBox 后看图** 为准，不要假设本机有 tesseract/Vision 脚本。

## 前置（缺一不可）

1. 先跑 [locate-machine-probe](sand-workflow:locate-machine-probe)，锁定角色=**Pro**。指纹/零命中就停，请重连本机，不要继续点微信。单机入口 [macbook-pro-probe](sand-workflow:macbook-pro-probe) 亦可，但串机时必须升全量扫。
2. 权限：`Grok Bot`（`com.anysphere.sand`）需 **辅助功能** + **自动化**（WeChat / System Events）。需要截屏时确认屏幕录制已开。`-25211` / `-25208` 出现就停，让辉哥在系统设置里重开勾选（勿擅自 `tccutil reset`）。
3. 微信已登录；同一任务内窗口几何保持稳定（例如 `{80,40}` / `{1100,800}`）。
4. 截图目录：`~/.grokbot/wechat/`。发前、贴草稿后、发送后各留一张。

## 硬规则

- **发送前必须截图核对标题**：目标名是会话标题的前缀/主体即可（例如目标 `吴泽楷团队`，标题 `吴泽楷团队 (5)` 算通过）；若标题是别的群/人（含 PMP、老婆亲亲等）→ 不粘贴、不回车。
- **每次按 Return 之前再截/再认一次标题**（防止等确认期间辉哥或系统切了会话）。
- **禁止凭记忆坐标盲进会话**。默认请辉哥点开目标；助手主责是核对 + 起草 + 发送。
- **搜索框禁止 Return「打开会话」**。Return 易进搜一搜，或把查询字发进当前群。搜到后只点本地 **联系人/群聊** 结果行，再验标题。
- 搜一搜/文章视频侧栏挡操作时先 Esc；确认中间栏是聊天再动手。
- System Events `click at` 不稳可用 JXA `CGEvent`；**选会话仍以标题核对为准**。
- 侧栏标签不可信；动手前探针，长任务中途再探针。
- 撤回有约 **2 分钟** 时限；超时只能如实告知辉哥。

## 推荐流程

### A. 辉哥已打开目标会话（默认）

1. 探针通过 → 激活微信 → 截整窗。
2. 核标题（见上）。失败则停。
3. 通读可见上下文；已问过的不重复。
4. 清空输入框脏草稿 → 粘贴草稿 → 截图给辉哥看输入框文案。
5. 辉哥说「发 / 发送」→ **再核一次标题** → `Return` → 再截一张，确认绿气泡在同一会话。
6. 多条：一条确认后再发下一条。

### B. 助手自己打开会话（仅必要时）

1. `Command+1` 聊天列表；Esc 清搜一搜。
2. 目标若在左侧可见：优先 **方向键** 移动选中，每步截图验标题。不要连点估计坐标。
3. 不在列表：`Command+F`（或左侧搜索）写入精确名 → **只点本地群聊/联系人行**。若出现文章/视频/AI 搜，视为失败：停，请辉哥手动打开一次。
4. 标题核对通过后进入 A 第 3 步。
5. 本机无可靠 OCR 工具时，不要假装「OCR 点击」；改为截图人工（助手看图）确认或请辉哥点开。

### C. 写入与发送

1. 焦点在输入框（可试 Tab；不稳就点输入区后截图确认光标/草稿位置）。
2. **用剪贴板粘贴整句**。不要依赖 AXValue（当前微信 AX 常只有窗口按钮）；少用逐字 keystroke（输入法会改字）。
3. 发送用 `Return`，不要点坐标「发送」按钮。
4. 辉哥若说「直接发」：仍必须完成标题双检（贴草稿前 + Return 前）；不豁免核对。

## 口吻

- 先读该会话最近几条再仿写；勿公文腔。
- 家人可短句俏皮；商务更短、少表情。
- 转账、承诺、约见面等重大决定先问辉哥。

## 必须停手

- 探针串机 / 权限失败 / 标题核对失败 / 搜一搜抢焦点
- 误进错误会话（立刻停；2 分钟内尝试撤回，否则告知）
- 未确认发送（除非本任务明确「直接发」且双检已过）
- 支付、删好友、退群、清空聊天
- Shell/本机操作被安全审核连续拦住且无法探针

## 失败速查

| 现象 | 处理 |
|------|------|
| 侧栏写 MacBook、探针是 Mini/Air | 停；请重连 |
| 搜索后文章/视频 | 搜一搜；Esc；改请辉哥点开 |
| 输入框群名重复 | 脏草稿；全选删除 |
| `-25208` | 停或改 JXA；勿 reset TCC |
| 中文被输入法改 | 整句 pbcopy + ⌘V |
| 本机 python/xcrun 坏 | 不用第三方 OCR 脚本；截图看图 |

## 不要做

- 编造屏幕上没看到的内容
- 把验证码/支付密码写入 skill 或记忆
- 未核标题就发送
- 继续已取消的代发任务
- 依赖未在本机验证过的外部 wechat 脚本当唯一路径
