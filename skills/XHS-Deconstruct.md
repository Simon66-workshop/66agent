# XHS Deconstruct · v0.1

只拆 `XHS-Evidence-Judge.md` 标成 **P0 或高 P1** 且 `advance: yes` 的条目。`advance` 只出现在打分前已打开、证据 ≥ L1 的笔记上；L0 不到这里。  
每跑最多拆 **3** 条。其中需要播放视频的，最多 **1** 条（对齐采集预算里的「深拆从紧」，不是把抖音采集器改成小红书）。

详情入口沿用信号卡上的 `/search_result/{id}?xsec_token=`。不要改去裸 `/explore/{id}`，也不要编造 token。打分前若已读到 L1，本步从该页接着做，不重复占「打分前 5 条」的名额。

评论只在评论区真实打开后摘录，每条笔记最多 **8** 条可见评论。父评论对不上笔记就标 UNKNOWN，不要靠位置猜。

## 证据等级

| 等级 | 含义 | 可以写 | 不可以写 |
|---|---|---|---|
| L0 | 只有搜索列表/摘录 | 标题摘录、为何进池 | 正文结构、口播、镜头 |
| L1 | 打开笔记页，读了标题 + 封面 + 可见正文 | 封面字、标题、正文节拍（标「来自正文」） | 「看过视频 / 看完全部图」 |
| L2 | 正文已读完，且每一张可见图都打开过 | 图上文字与图序 | 未播放的视频画面、BGM、口播原句 |
| L3 | 播放器实际播放，并留下回执 | 回执时间范围内的画面/口播 | 回执之外的「全片看完」 |

回执最少要有：笔记 URL、播放器显示的时长（没看见写「未找到」）、实际播放的起止（例如 0:00–0:21）、操作者是人还是 Agent、时间（+08:00）。缺任何一项，**最高 L2**（视频笔记若图文都没看全，则停在 L1）。

禁止：没有 L3 回执却写「已观看」「看完」「导演级拆解已覆盖成片」。

## 步骤

1. 确认 Judge 档位与 Jev 标记。硬门禁丢弃的不拆。
2. 打开笔记。打不开 → `BLOCKED` 或 `FAILED`，不编正文。
3. 先记录等级，再写结构。等级不够的格子写「未观察」或「未找到」。
4. 视频默认不播放。只有当次预算里的那 1 条，且人已允许打开播放器，才做到 L3。
5. 输出拆解卡。不写可发布正文（那是 Converter）。

## 拆解卡

```text
url:
judge_grade:
evidence_grade: L0|L1|L2|L3
observed:
  title:
  cover:
  body_text: 摘录或「未找到」
  images_opened: 0/n 或「未找到」
  video_receipt: 无 | 附回执四字段
hook:
  cover_title:
  first_line:
  evidence: 哪一级看见的
structure:
  beats: 只根据已观察文本/图；推断的节拍标 INFERENCE
pain:
pleasure:
cta: 屏上原句；没有写「未找到」
tags: 屏上话题标 FACT；自己补的标 INFERENCE
comment_sample: 打开了才写，最多 8；否则「未找到」
counterevidence:
cannot_claim:
access: OK | BLOCKED | FAILED
```

痛点 / 爽点如果不是原文，标 INFERENCE，并写反证（什么样的评论或正文会推翻它）。

## 禁止

- 用「爆款公式」填未观察的镜头
- 把 L1 正文改写成「看过视频后的结论」
- 编点赞、收藏、播放、粉丝
- 抄全片字幕当自己的观察（没播放就没有字幕观察）
- 发布、关注、评论、私信
- 绕过登录或验证码；挡住就 BLOCKED

## 验收

- [ ] 只有 P0 / 高 P1，且 ≤3；视频播放 ≤1 并有回执才是 L3
- [ ] 无回执的视频笔记没有「已看完」
- [ ] 钩子、CTA、标签能指回等级
- [ ] 推断与原文分开
- [ ] 评论未打开则为「未找到」
