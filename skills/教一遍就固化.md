# 教一遍就固化

辉哥当面演示过、能在 10 分钟内复跑的流程，才写成 skill。没演示过的不编、不猜步骤。

## 什么时候写

- 辉哥演示了一遍，或带着你当场跑通
- 全程大约 ≤10 分钟，步骤稳定
- 写完立刻双写：GitHub `skills/` + 本地 `/Volumes/2T扩展盘/Agent文件/skills`，并更新 `skills/README.md`

## 怎么写

1. 只写实际走过的步骤、真实入口 URL、停下来交给辉哥的点。
2. 保持短、可执行。不要抄官方长清单。
3. 官方总览只引用：https://docs.x.ai/grok-bot/overview
4. 密码、token、设备码、卡号不准写进 skill、日志或 git。

## 必须停、交给辉哥

付款、外发、删除、上线、2FA / 验证码 / 账号锁。没点头不要代做，不要代填。

## 不要做

- 把没演示过的流程编成 skill
- 新开第五个 Bot，或把冻结的 `Grok编排总控助理_*` 当活入口
- 以为拆给多个 Bot 就是隔离。四人共用一台电脑的文件和登录态
