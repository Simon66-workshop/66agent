# Boss 直聘：发前核对象（防发错人）

凡在 MacBook Pro 的 BOSS直聘里**粘贴、常用语发送、回车/点发送**之前必跑。由 2026-09-12 事故固化：想搜「田今磊」时把名字糊进 Xander 对话框。配合 [boss-message-screen](sand-workflow:boss-message-screen)、[boss-zhipin-click](sand-workflow:boss-zhipin-click)、[locate-machine-probe](sand-workflow:locate-machine-probe)。对标微信侧 [wechat-mac-reply](sand-workflow:wechat-mac-reply) 的标题双检。

## 硬规则（缺一不可）

1. **目标姓名先写死**：本轮只服务一个 `{target_name}`。换人先结束上一轮，重新截图。
2. **粘贴/发送前必须截图核顶栏姓名**：右侧聊天顶栏显示的候选人名必须等于 `{target_name}`（可带「今日活跃」等后缀，但主体名一致）。**对不上 → 不粘贴、不点发送、不清空别人草稿除非确认在目标框。**
3. **点发送 / Return 前再截一次**（双检）：防止等待期间会话被切走。
4. **禁止把「搜索用人名」粘进聊天输入框**。搜索只能点列表上方搜索框，且粘贴人名后**禁止 Return 当发送**；只点搜索结果行，再核顶栏。
5. **列表点选不稳 / `osascript` 报辅助访问 `-25211` / click 总停在同一人**：立刻停自动点选。请辉哥点开目标会话，或先修好辅助功能；**禁止**为了换人而在当前输入框试搜、试粘贴人名。
6. **草稿里出现其他候选人姓名**（非本轮 target）：视为污染，整段删掉重写，不得发送。
7. 发错后：能撤就撤；否则立刻发一句道歉说明发错，再停手汇报辉哥。

## 推荐流程

### A. 默认（辉哥或已可靠点开目标）

1. 探针锁定 Pro → 激活 BOSS直聘 → 固定窗口几何（见 boss-zhipin-click）
2. 截整窗 → **认顶栏姓名 == `{target_name}`**
3. 通读上下文；起草（剪贴板）
4. 再截一张确认仍是同一人 → 粘贴到输入框 → 截图确认草稿内容且无错名
5. 再核顶栏 → 点 **发送**（或常用语条旁发送）→ 截图确认气泡在同一会话

### B. 需要换人

1. 优先：辉哥点开下一位；或方向键逐个移动并**每步截图验名**
2. 搜索换人：只点消息列表搜索框（先截图确认焦点不在聊天输入区）→ 粘贴精确名 → **只点结果行，禁止 Return** → 核顶栏
3. 焦点分不清（输入框 vs 搜索框）→ **停**，请辉哥点开，不要赌

### C. 权限失败

- 出现「osascript 不允许辅助访问」等：停止一切 click/keystroke 换人；只允许截图只读；告诉辉哥开：系统设置 → 隐私与安全性 → 辅助功能

## 事故对照

| 错误做法 | 正确做法 |
|---|---|
| 当前停在 Xander，往输入框粘「田今磊」当搜索 | 先确认焦点在列表搜索框，或让辉哥点开田今磊 |
| 点选失败仍继续 pbcopy + Return | 停；核名通过前不发 |
| 一条消息里混进其他人姓名 | 删掉重写 |

## 不要做

- 盲坐标连点列表赌换人成功
- 用聊天输入框当搜索框
- 未核顶栏就发常用语/粘贴
- 辅助功能失败时强行自动化外发
