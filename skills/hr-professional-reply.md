# 专业招聘回复（网上 + GitHub 蒸馏）

给 Boss 直聘等即时聊天用。操作流程跟 [boss-message-screen](sand-workflow:boss-message-screen)；剪辑岗业务口径跟 [boss-editor-chat](sand-workflow:boss-editor-chat)；点选跟 [boss-zhipin-click](sand-workflow:boss-zhipin-click)。口吻可口语（辉哥风格），骨架要专业。

## 原则（可执行）

1. **先读再回**：通读聊天 + 顶栏经历/期望；已问过的不重复。
2. **硬条件先判**：岗位对口、到岗方式（到店/居家）、城市、是否学徒 vs 熟手。硬不匹配 → 软拒或说明，不硬聊。初筛宽、材料到手再严评。
3. **一条消息三件事**：你现在处在哪 → 下一步要对方做什么 →（能说时）大概何时再回（stand / next / when）。多数消息短句，一次只推进一件事。
4. **个性化一句**：点出对方经历、作品或问题里的一个具体点；忌「看了您简历很优秀」万能句。
5. **答完必反问**：候选人问条件时，如实答 → 一句岗位吸引点 → 立刻反问匹配项；避免纯答疑机器人。
6. **快回、不晾着**：新招呼及时回；不合适也回一句，忌已读不回当默认拒绝。
7. **条件未知就 Hold**：薪资/作息/社保无辉哥原话 → 明确「核实后回」，可问对方期望；**绝不编数字**。
8. **敏感与合规**：不问婚育/性别偏好等歧视内容；不虚假「一定留档」；反馈只谈岗位相关。

## 发出前自检

`有锚点？有下一动作？有时限（能说时）？数字是否核实？有无歧视？拒绝是否诚实？`

## 阶段骨架（填空，勿整段公文）

### A. 新招呼开场（推进）
```
你好{称呼可选}，看了你{具体一点：岗位/经历/作品}。我们这边是{一句话业务}。方便发下{简历/作品}看看吗？{可选追问一个硬条件}
```
改装岗可叠：「您好，方便看看你的简历吗？另外您对这个汽车改装行业喜欢吗？」  
剪辑岗可叠 boss-editor-chat（口播IP+展示号、AE、抖音 `66_Workshop`）。

### B. Hold（待遇未定）
```
你好，收到了。{岗位内容可先说}。薪资/作息我确认下再回你，不想随口报不准的。方便的话先发简历/作品，也说说你的期望区间～
```

### C. 追问 / 澄清必备（一次 1～2 个）
```
先对齐下：①{必备1} ②{必备2}。这两点你目前都 OK 吗？有哪条接近但不完全符合也可以直说。
```

### D. 体面软拒（已定口径可发）
感谢 → 明确不推进 → 岗位向原因（短）→ 祝福。勿假承诺以后联系。  
已验证：「你好，看了，不太合适，不好意思」  
稍完整：「感谢你的兴趣～我们这边更看{岗位核心}，目前可能先不太合适，谢谢你～」  
居家兼职：「不行呢，我们需要到岗的」

### E. 高匹配推进
说明兴趣点 + 要材料或约下一步；**换微信 / 换电话 / 约面 / 录用 → 先叫辉哥**。

## 不要做

- 群发无锚点长模板；已读不回；编薪资/作息/社保；挂高薪入职砍价
- 歧视性问题；人格评价；审讯式连环提问
- 假承诺「一定再联系」；点「不合适」前先问辉哥
- 往云电脑登 Boss
