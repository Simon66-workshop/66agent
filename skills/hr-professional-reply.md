# 专业招聘回复（网上 + GitHub 蒸馏）

给 Boss 直聘等即时聊天用。操作流程跟 [boss-message-screen](sand-workflow:boss-message-screen)；剪辑岗业务口径跟 [boss-editor-chat](sand-workflow:boss-editor-chat)；点选跟 [boss-zhipin-click](sand-workflow:boss-zhipin-click)。口吻可口语（辉哥风格），骨架要专业。

## 原则（可执行）

1. **先读再回**：通读聊天 + 顶栏经历/期望；已问过的不重复。
2. **硬条件先判**：岗位对口、到岗方式（到店/居家）、城市、是否学徒 vs 熟手。硬不匹配 → 软拒或说明，不硬聊。
3. **一条消息三件事**：你现在处在哪 → 下一步要对方做什么 →（能说时）大概何时再回。参考招聘邮件框架：stand / next / when。
4. **个性化一句**：点出对方经历、作品或问题里的一个具体点（GitHub sourcing 同理：提具体作品，不群发空话）。无差别复制粘贴会降回复率。
5. **快回、不晾着**：新招呼尽量及时回；不合适也要回，忌已读不回。
6. **核心话术就几类**：确认收到 / 推进要材料 / 暂缓待确认 / 体面婉拒。够用即可。
7. **敏感与合规**：不问歧视性内容；不编待遇；不虚假「一定留档/以后一定招」；反馈只谈岗位相关。

## 阶段骨架（填空，勿整段公文）

### A. 新招呼开场（推进）
```
你好{称呼可选}，看了你{具体一点：岗位/经历/作品}。我们这边是{一句话业务}。方便发下{简历/作品}看看吗？{可选追问一个硬条件}
```
改装岗可叠已验证句：「您好，方便看看你的简历吗？另外您对这个汽车改装行业喜欢吗？」  
剪辑岗可叠 boss-editor-chat（口播IP+展示号、AE、抖音 `66_Workshop`）。

### B. 确认收到 / 暂缓（待遇未定等）
```
你好，收到了。{岗位内容可先说}。{薪资/作息}我确认下马上回你哈～方便的话先发简历/作品我看看。
```
**无辉哥原话数字绝不编。**

### C. 追问筛选（一次 1～2 个）
优先：相关经验年限、成片/项目例子、能否到岗、期望到岗时间。一次别连珠炮。

### D. 体面软拒（已定口径可发）
结构：感谢 → 明确结果 → 岗位向原因（短）→ 祝福。  
已验证口语：「你好，看了，不太合适，不好意思」  
稍完整：「感谢你的兴趣～我们这边更看{岗位核心}，目前可能先不太合适，谢谢你～」  
居家兼职（已演示）：「不行呢，我们需要到岗的」

### E. 高匹配推进
说明兴趣点 + 要材料或约下一步；**换微信 / 换电话 / 约面 / 录用 → 先叫辉哥**（见 boss-message-screen 停点）。

## 不要做

- 群发无个性化长模板；已读不回；编薪资/作息/社保
- 人格评价、年龄性别地域挖苦、歧视性问题
- 假承诺「一定再联系」；点「不合适」前先问辉哥（演示未授权自动点）
- 往云电脑登 Boss
