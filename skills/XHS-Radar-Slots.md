# XHS Radar Slots · v0.1

默认赛道（66Workshop 小红书，不是 X Radar）：**汽车改装（刹车系统 / 避震低趴）× AI/AIGC 做内容的方法 × 实体店经营**。

X 的「汽车不进 Radar」只约束 `skills/X-Radar-5核心.md`。本文件服务小红书选题，汽车方法题是默认，不是例外。

Query 是给人/Agent 贴进小红书搜索或话题页的词，**不是** X 布尔语法。小红书是否支持 `OR` / `-` 操作符 = **UNKNOWN**，不要假装能用 X Query。

账号、对标号、主页链接放 routine 或 agent 记忆，**不要**写进本 skill。

## 槽（5）

每个槽一轮最多打开搜索结果 **4** 条笔记（全流程上限见 `XHS-Topic-Pipeline.md`）。优先标题或可见正文里带步骤、数字、对比的笔记。纯新闻、纯报价、招聘不进池。

### 1. [P0-BRAKE] 刹车系统方法

- 搜索：`刹车异响 怎么查`、`刹车油 含水`、`刹车热衰减`、`电子手刹 排空`
- 要：盘 / 皮 / 油 / 油管 / 桥码 / 轮胎 / 安装 / 调校里的可复现步骤或数字
- 不要：最低价、秒杀、招聘、恐吓式「不改就出事」

### 2. [P0-SUS] 避震与低趴

- 搜索：`避震 低趴 怎么选`、`轮毂净空 避震`、`避震 软硬`
- 要：工况、净空、电子手刹、路试标准
- 不要：把「越低越好」当结论；不要包围 / 氛围灯

### 3. [P0-HANDOFF] 施工与交车验收

- 搜索：`交车 试刹车`、`刹车油 排空 步骤`、`四轮定位 验收`
- 要：车主能当场复验的动作
- 不要：只晒完工图、没有步骤

### 4. [P1-AIGC] 用 AI/AIGC 做这条内容

- 搜索：`小红书 封面标题`、`汽车笔记 结构`、`AIGC 封面 翻车`
- 要：封面、标题字数、分镜或翻车复盘（方法）
- 不要：模型发布新闻、没有做法的「AI 又更新了」

### 5. [P1-STORE] 实体店经营

- 搜索：`改装店 获客`、`到店 信任`、`刹车 复购`
- 要：交付、信任、复购、到店决策
- 不要：招聘、代运营卖课、只报流水没有做法
