# 小红书赛道具体数据源清单

**版本**: 1.0  
**适用**: 研究助理处理小红书商业机会、竞品、内容变现研究时强制参考  
**最后更新**: 2026-08-18

---

## 1. 官方与半官方数据源（最高可信）

| 来源 | 说明 | 用途 | 获取方式 |
|------|------|------|----------|
| **小红书创作者中心** | 账号后台数据中心 | 自己账号曝光、互动、粉丝画像 | 登录创作者中心 |
| **小红书灵犀** | 官方智能洞察平台（企业专业号可免费使用） | 品类趋势、人群洞察、SPU口碑、搜索热度、竞品对比 | 企业专业号开通后使用 |
| **蒲公英** | 小红书官方商业合作平台 | 达人报价、商业笔记数据、投放效果 | pgy.xiaohongshu.com |
| **小红书话题广场 / 搜索** | 公开话题与笔记 | 内容热度、用户真实讨论 | App / 网页搜索 |

---

## 2. 第三方专业数据工具（高可信，需付费）

| 工具 | 核心优势 | 适合场景 | 备注 |
|------|----------|----------|------|
| **千瓜数据** | 小红书专项最深，种草链路、爆款拆解、品牌监测强 | 品牌种草、竞品内容分析、达人筛选 | 价格较高，品牌向 |
| **新红（新榜旗下）** | 性价比高，功能全面，榜单与投放分析好 | 中小品牌、个人运营、竞品对比 | 性价比推荐 |
| **灰豚数据** | 价格最低，基础功能够用，品牌PK报告 | 预算有限的个人/小团队 | 数据深度一般 |
| **飞瓜数据** | 小红书+抖音双平台，电商带货数据强 | 同时做两平台的电商竞品 | 偏电商 |
| **新榜声量通** | 多平台声量、舆情、传播路径 | 跨平台品牌声量监测 | 全域监测 |

**选择建议**：
- 预算充足品牌 → 千瓜
- 性价比优先 → 新红
- 个人/小预算 → 灰豚 + 官方灵犀
- 电商导向 → 飞瓜 / 蝉妈妈（偏抖音但可参考）

## 3. 辅助与公开信号源

- **X (Twitter)**：搜索「小红书」+ 相关赛道关键词，关注运营者、品牌方讨论
- **QuestMobile / Sensor Tower**：整体App趋势与用户规模（宏观）
- **SimilarWeb / Semrush**：网页流量参考（有限）
- **GitHub / 开源项目**：如果涉及小红书相关工具或插件
- **行业媒体**：36氪、虎嗅、晚点中关于小红书生态的深度报道

---

## 4. 使用原则（强制）

1. **优先官方**：灵犀 + 创作者中心 + 蒲公英 能解决的先用官方。
2. **第三方交叉**：千瓜 / 新红 / 灰豚 数据需与官方或真实笔记抽样交叉验证。
3. **注意偏差**：第三方工具存在数据延迟、采样偏差、营销笔记干扰，必须抽样真实笔记验证。
4. **标注来源**：所有结论必须写明「数据来自千瓜 / 灵犀 / 真实笔记抽样」等。
5. **时效性**：优先近 30-90 天数据。

---

## 5. 与研究SOP的结合

研究助理在做小红书相关商业机会分析时：
1. 先查本清单确定数据源
2. 执行《商业机会与商业内容研究SOP》的验证清单
3. 输出时明确标注使用了哪些具体数据源
