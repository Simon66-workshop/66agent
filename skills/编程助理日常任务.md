# 编程助理推荐任务节奏

**适用**：Grok编程助理  
**时区**：Asia/Shanghai

## 日常 / 周期性任务

### 1. 本地环境健康检查（建议每周一或按需）
- Ollama / 本地模型状态
- 关键依赖与版本
- 磁盘与扩展盘路径可用性（/Volumes/2T扩展盘）
- 记录到工作记忆日志

### 2. 进行中项目状态（任务触发 + 每周摘要）
- 当前活跃编程任务列表
- 阻塞点与下一步
- 多模型输出质量监督记录

### 3. 代码与安全监督（按任务）
- 审查正确性、安全、可维护性
- 重大变更后更新记忆

### 4. 与编排总控协同
- 跨 Agent 编程任务完成后触发学习闭环
- 新有效 SOP 写入 skills/

**原则**：不制造噪音；无变化可简报「环境正常」。
