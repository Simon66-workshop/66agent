# Boss 直聘：识别并点击（MacBook Pro）

对本机操作前先跑 [locate-machine-probe](sand-workflow:locate-machine-probe)（角色=Pro）或 [macbook-pro-probe](sand-workflow:macbook-pro-probe)。

## 硬门禁（2026-09-13 辉哥确认）

**点开任何候选人 / 点列表换人之前，必须先排干净「意向沟通」营销弹窗**（文案常含「牛人不回应」「购买权益」等）。这是点错界面的主因。

1. 截整窗：若看到意向沟通 / 购买权益卡片或蓝头栏 → **先关弹窗，再点人**。
2. 关法：优先点卡片右上角 **X**；Esc 常无效。
3. **X 打不中、点飘、或误进购买页** → 立刻 `quit` + `open` 重开 BOSS直聘，不要连点、不要让辉哥反复手关。
4. 重开后再次截图确认无弹窗，才进入列表点人。

## 原则

1. **先固定窗口几何**，再点绝对坐标（Electron AX 经常为空）。
2. 点之前/之后都截屏核对；点错立刻 Esc / 关弹窗。
3. 清「新招呼」时职位下拉先选 **全部职位**，再点「新招呼」；只筛单岗时列表可能显示「暂无牛人」但角标仍有数字。
4. 列表点选不稳时：重开后用联系人搜索（顶栏旁放大镜 →「搜索姓名/群聊」→ 粘贴名 → **只点下拉联系人行，禁止 Return**）；每次发送后截图确认气泡。窗口偶发跑到副屏（负坐标）时先拖回 `{100,50}`。
5. **Retina**：`screencapture` 图常是 2× 像素；用 OCR/色块算点击时先 `/scale` 再加 crop 原点。

## 固定窗口

```
position {100, 50}
size {1400, 900}
```

| 附件简历 | `{1370, 108}` |

## 同意接收附件简历（2026-09-12 辉哥手点验证）

1. 触发后会出现：**顶蓝条**「对方想发送附件简历…」+ **聊天内卡片**「拒绝 / 同意」。
2. 点 **同意**（蓝底白字）。成功后：打开附件简历浮层（PDF），聊天里出现 `xxx.pdf` +「点击预览附件简历」。
3. **自动化注意**：CGEvent HID / Session tap / System Events `click at` 对这个 Electron 按钮**经常点不中**（坐标算对也无效）。流程：
   - 先 OCR TSV 定位「同意」文字中心再点一次；
   - **仍无浮层 / 蓝条还在 → 立刻请辉哥手点「同意」**，不要连点十几次；
   - 辉哥点完后截屏确认浮层或 pdf 预览条出现，再继续。
4. 关浮层：Esc 或右上角 **X**；关后核顶栏姓名未变。

## 打开附件简历流程

1. 探针通过 → 激活 `BOSS直聘` → 固定窗口几何 → **硬门禁排弹窗**
2. 确认当前候选人会话（截屏核对标题）
3. 若有「是否同意接收附件」→ 先点 **同意**（见上节；点不中就请辉哥）
4. 点 **附件简历** /「点击预览附件简历」或聊天预览
5. 加载中等 3–8 秒再截屏
6. CopyToBox 阅读；结论写入 [boss-candidate-index](sand-workflow:boss-candidate-index)
