# 影哨自动换线值守

辉哥要 Mini 24 小时不断网时用。影哨对本机节点做 TCP 测速，按界面点选 Shadowrocket，超时改线。菜单栏约 10 秒刷新 ↑↓ 和延迟。不要用助手电脑的网络顶 Mini。

仓库：https://github.com/Simon66-workshop/yingshao  
安装说明以仓里 `GROK_BOT.md` 为准。

**在 PR 合进 main 之前，安装和重编都只用已验收分支，不要 clone 默认 main。**  
当前已验收分支：`cursor/inprocess-applescript-tcc-c204`（[PR #1](https://github.com/Simon66-workshop/yingshao/pull/1)）。main 合入后，把本节改成默认分支。

## 何时用

「装影哨」「夜间值守」「自动换节点」「Shadowrocket 超时了切一下」「菜单栏网速」「kickstart 影哨」「24 小时观察还会不会断网」。

## 前置

- 机器：Apple 芯片 Mac Mini（arm64）。本机不关电。干活在 Mini，聊天可以在 AirBook。
- 已装 Shadowrocket，保持打开、全局路由按辉哥当前设置。
- 有 `swiftc`、`git` 或 `gh`。
- 辉哥已授权本机 `screencapture` 看 Shadowrocket。

## 稳定目标

- App：`~/Applications/Yingshao.app`
- 配置：`~/Library/Application Support/Yingshao/config.json`
- 状态：同目录 `status.json`
- 日志：`~/Library/Logs/Yingshao.log`
- 常驻：`gui/$(id -u)/com.yingshao.sentinel`（RunAtLoad + KeepAlive）
- 菜单栏：`↑xx ↓xx  NNms`（约 10 秒，不点 Shadowrocket，不跑 speedtest）
- 观察日志：优先 `/Volumes/2T扩展盘/Agent文件/yingshao-watch/`；CopyFromBox 写不进 2T 时，先写 Mini `~/yingshao/yingshao-watch/` 和助手侧 `/workspace/yingshao-watch/`，能写 2T 再归档。

## 安装（没装过）

1. 读仓里该**已验收分支**的 `GROK_BOT.md`，按它做。不要发明步骤。
2. `git` 若走死代理 `127.0.0.1:7897`：这次命令去掉代理，或改用 `gh` tarball。不要死磕。
3. 拉已验收分支，不要默认 main：

```
cd "$HOME"
git clone --branch cursor/inprocess-applescript-tcc-c204 --single-branch \
  https://github.com/Simon66-workshop/yingshao.git
cd yingshao
bash install.sh
```

或：`gh api repos/Simon66-workshop/yingshao/tarball/cursor/inprocess-applescript-tcc-c204` 解到 `~/yingshao` 再 `bash install.sh`。
4. 编译要带：Foundation、Network、IOKit、AppKit。`kIOPMAssertionTypePreventUserIdleSystemSleep` 必须 `as CFString`。
5. 配置：辉哥如果给订阅 URL，只写入本机 `config.json` 的 `subscription_url`。不要写进聊天、不要写进 skill、不要写进 66agent。他不给 URL：从已导入的本地节点填 `nodes`（只要 name/host/port/enabled）。不要导出 UUID、token、整份 ServerManager。
6. 打开辅助功能页：`open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility"`  
   打开自动化页：`open "...?Privacy_Automation"`  
   **停**：辉哥本人勾「影哨」，并允许控制 System Events / Shadowrocket。不要代点。
7. `launchctl kickstart -k "gui/$(id -u)/com.yingshao.sentinel"`
8. 看日志出现「影哨启动」和心跳。菜单栏应出现 ↑↓ 和 ms。

## 日常换线 / 验收

1. 先读 `status.json` 和日志尾。结论跟界面选中行走，不跟影哨 TCP 单独走。
2. 本机 `screencapture` 拍 Shadowrocket：当前节点、连通性测试、本地节点、谁超时。
3. 需要立刻切一次：`"$HOME/Applications/Yingshao.app/Contents/MacOS/yingshao" once`（这是影哨自己点选，不是助手桌面自动化）。
4. 编完验收：`yingshao match-check` 要 `match-check passed`。
5. 锁定某条（例如正在用的好线）：配置里 `pin` 写成节点全名。锁定仍在、这条界面超时，才允许改线。
6. 改配置或重编后 kickstart。重签名后辅助功能常掉（错误 `-25211`）：再打开辅助功能页，**停**，让辉哥把「影哨」关掉再打开。

## 24 小时观察（断网取证）

辉哥说「看看还会不会断网」时开一份有限期观察，不是永久每 30 分钟骚扰。

1. 建观察日志目录（见上，优先 2T）。
2. 每 30 分钟拉 `status.json` + 日志新行，追加一条：上海时间、connected、last_ms、ok、message、新错误。不要写订阅/密钥/host:port。
3. 正常（还是同一节点、ok、有 ms）：保持安静，不要报「还是一样」。
4. 只在这些情况叫人：Mini 通道断了、connected 变了、ok 变 false、日志出现超时或 `-25211`、last_ms 空了。
5. 观察期间不要 kickstart、once、改 pin、点 Shadowrocket。
6. 满 24 小时写摘要、日志留下修 bug、删掉这份观察 routine。常驻值守本身不要停。

## 重编（菜单栏 / 点选修过之后）

源码只以 GitHub **已验收分支** 的 `yingshao.swift` 为准。先拉到本机工作副本再编，不要写死 `yingshao-pr1.swift` 这种临时文件名。

```
BRANCH=cursor/inprocess-applescript-tcc-c204
SRC="$HOME/yingshao/yingshao.swift"
gh api "repos/Simon66-workshop/yingshao/contents/yingshao.swift?ref=${BRANCH}" --jq .content \
  | base64 -d > "$SRC"
swiftc -O -target arm64-apple-macos12.0 \
  -framework Foundation -framework Network -framework IOKit -framework AppKit \
  -o "$HOME/Applications/Yingshao.app/Contents/MacOS/yingshao" \
  "$SRC" \
&& codesign --force --sign - --identifier com.yingshao.sentinel \
  "$HOME/Applications/Yingshao.app" \
&& launchctl kickstart -k "gui/$(id -u)/com.yingshao.sentinel"
```

本机命令通道批不了时，把上面整段给辉哥在 Mini 终端跑。不要绕 Always allow。

## 必须停

- 辅助功能 / 自动化勾选、关开「影哨」
- 登录、2FA、YubiKey、付款
- 推 `main`、删节点、Disconnect QuotaBar
- 订阅 URL、UUID、密码：不要写进聊天或 skill；订阅 URL 如需使用，只写本机 `config.json`

## 失败模式

| 现象 | 原因 | 怎么做 |
| --- | --- | --- |
| 切换未确认 / 辅助功能 | 旧版 spawn `osascript`，或重签名掉权 | 确认二进制是进程内 NSAppleScript；让辉哥重勾影哨 |
| `-25211` 不允许辅助访问 | codesign 后 TCC 掉了 | 停，辉哥关开「影哨」 |
| 日志写切成功，界面还在超时节点 | `once` 和 launchd 各一份脑子；TCP 14ms 但界面超时 | 以界面为准；新版应共享 status.json，且不点「超时」行 |
| `未找到匹配节点` 但列表有这个名字 | Mac 版是 SwiftUI 行，不是 table | 用已验收分支的 AX 匹配（全名 / 去空格 / IP） |
| git 连不上 7897 | Mini 代理没开 | 去代理或 `gh` tarball |
| 批准卡 Mini / AirBook 都没有 | 本机执行通道没挂上 | 不要假装已执行；把命令给辉哥贴 Mini 终端 |
| 菜单栏没有 | 没带 AppKit 或没 kickstart | 按重编命令，带 AppKit |
| Mini 通道突然 CopyToBox 失败 | 这就是 24 小时观察要抓的断网 | 记日志并叫人；不要在观察窗口里乱 kickstart |

## 不要做

- 不要用 Shell `osascript` 点 Shadowrocket
- 不要用助手电脑的桌面自动化 / Computer / 二进制去驱动 Mini 上的 Shadowrocket 界面（点选只许影哨.app 自己做）
- 不要每 10 秒点一次连通性测试
- 不要跑 speedtest / 全量扫来刷菜单栏
- 不要把订阅链接、密钥、host:port 清单贴到聊天或写进 skill
- 不要点 Codex、不要点 QuotaBar Disconnect
- 不要推 main
- 不要用盒子 IP 或盒子浏览器顶 Mini 出口
- 不要 clone/安装默认 main，在已验收分支合入之前

告诉辉哥：当前节点、last_ms、菜单栏是否在、pin 是否还锁着、日志有没有 `-25211`。Mini 不关电。说「完成任务了，辉哥」。
