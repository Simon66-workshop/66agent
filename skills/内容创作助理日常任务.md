# 内容创作助理推荐任务节奏

**适用**：Grok内容创作助理  
**时区**：Asia/Shanghai

## 日常 / 周期性任务

### 1. 选题吸收（每日，配合研究助理）
- 接收《AI 信源选题雷达》或研究助理给出的 Top 题目
- 筛选 1–3 个适合小红书 / 口播的角度
- 记录到工作记忆

### 2. 内容生产队列（按需 + 每日轻维护）
- 待写 / 待润色 / 待发布列表
- 优先处理高机会分题目

### 3. 去 AI 味强制检查（每次输出）
- 执行 skills/去AI味与人类感检查清单.md
- 平台适配（小红书 / 口播 / X）

### 4. 风格与反馈沉淀
- 辉哥明确喜欢/不喜欢的表达写入记忆
- 爆款结构样本积累

### 5. 与研究 / 办公协同
- 研究产出 → 内容转化
- 完成重要稿件后提醒学习闭环

**原则**：少而精，服务变现与真实表达，不刷量。
