# 商业机会与商业内容研究 SOP（Skill）v1.1

**适用**：Grok研究助理（优先）  
**目标**：用可执行的自动化情报方法 + 高可信信息源，发现、验证、分析商业机会，输出简洁可行动汇报。

---

## 1. 高可信信息源清单（具体可点）

### A. 市场与融资情报（必查）
- Crunchbase / IT桔子 / 36氪 / 虎嗅（融资、公司动态）
- CB Insights / PitchBook 摘要（趋势报告）
- China AI Index（chinaidb.com）— 中国AI生态实时跟踪
- QuestMobile / Sensor Tower / SimilarWeb — 流量与App数据

### B. 社交平台与内容商业化（小红书重点）
- 小红书官方创作者中心 + 热门笔记搜索
- 千瓜数据 / 新红数据 / 蝉妈妈 / 飞瓜数据（第三方数据平台，有公开报告）
- X（Twitter）关键词 + 语义搜索（早期信号、创始人讨论）
- 知乎高赞回答 + 垂直专栏

### C. 竞品与产品动态
- 竞品官网 + 产品更新日志 / Changelog
- Product Hunt / GitHub Trending / Hacker News
- App Store / Google Play 评论与排名变化
- Meta Ad Library / 巨量引擎广告库（广告投放情报）
- Visualping / ChangeDetection 类工具监控竞品页面变化

### D. 权威报告与数据
- 艾瑞咨询、易观、QuestMobile 公开报告
- 公司财报 / SEC Filings（美股）
- 国家统计局 / 工信部公开数据

### E. 实时信号
- Google Alerts / 百度指数 / 微信指数
- X Lists + 关键词监控
- 行业 Newsletter（a16z, Stratechery, 36氪精选等）

**使用规则**：每个关键结论至少引用 2-3 个不同类别的高可信来源，并标注日期。

---

## 2. 竞品情报自动化策略（可落地）

### 2.1 日常自动化监控清单
1. **网站变化监控**：用 Visualping / 类似工具监控竞品定价页、功能页、博客
2. **社交监听**：X 关键词 + 小红书热门笔记定期搜索（研究助理用工具执行）
3. **融资与新闻**：Crunchbase / 36氪 / Google Alerts 关键词订阅
4. **产品发布**：Product Hunt + GitHub Release + 官网 Changelog
5. **流量与排名**：SimilarWeb / Sensor Tower 公开数据定期对比

### 2.2 研究助理执行流程（自动化优先）
- 接到任务后，先用 web_search + x_keyword_search + browse_page 并行拉取高优先级源
- 对关键竞品建立「监控清单」，记录上次检查时间与变化
- 发现重大变化（融资、大版本、政策、负面事件）立即标记高信号
- 每周或任务结束时，把监控结果写入工作记忆日志

### 2.3 工具组合（当前可用）
- Grok 内置：web_search、browse_page、x_keyword_search、x_semantic_search
- 外部可推荐：Visualping（页面变化）、SimilarWeb、千瓜/蝉妈妈公开报告、China AI Index

---

## 3. 真实性验证（升级版）

强制清单：
1. 来源是否属于上述高可信清单？
2. 是否有一手数据或可复现数字？
3. 至少 2-3 个独立来源交叉？
4. 时效性（优先近 90 天）？
5. 是否存在明显营销或利益相关？
6. 反面证据是否已主动搜索？

真实性评级：高 / 中 / 低。低评级只能作为假设。

---

## 4. 分析框架（保持第一性原理）

继续使用机会评分矩阵 + 第一性原理：
- 真正解决的痛点是什么？
- 价值如何被捕获？单位经济是否成立？
- 分发成本与护城河？
- AI 时代哪些环节成本骤降、哪些更稀缺？
- 时间窗口与监管风险？

---

```markdown
综合得分 X.X/10 | 优先级：高/中/低

## 2. 关键事实与来源（必须带来源+日期）
- ...

## 3. 竞品与市场信号
- 主要竞品动态（自动化监控结果）
- 流量/融资/内容表现

## 4. 第一性原理分析
- 痛点、价值捕获、单位经济、护城河

## 5. 风险与反面证据

## 6. 可行动建议 + 监测指标
```

## 6. 执行要求

研究助理接到商业机会/竞品/变现类任务时：
1. 优先加载本 Skill
2. 先拉高可信源 + 执行自动化检查
3. 严格验证真实性
4. 按模板输出简报
5. 更新工作记忆日志，重要新方法写入 skills/

此版本已从「框架」升级为「可执行情报手册」。
