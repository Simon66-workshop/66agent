# Boss 直聘：约人回店面试（跟学固化）

2026-09-12 辉哥在 Pro 上对 **Xander** 演示。只在 **MacBook Pro** 已登录的 `BOSS直聘` 跑。先 [locate-machine-probe](sand-workflow:locate-machine-probe)（角色=Pro），点选跟 [boss-zhipin-click](sand-workflow:boss-zhipin-click)，发前 [boss-send-guard](sand-workflow:boss-send-guard)，读写 [boss-candidate-index](sand-workflow:boss-candidate-index)。**没演示过的表单字段不要编。**

## 硬停点

- **点「约面试」/发出系统面试邀请之前** → 必须辉哥明确同意（人选、到店时间）
- 地址/门店信息无辉哥原话模板 → **停**，问辉哥，不猜
- 换微信 / 查看电话 / 录用 / 不合适 → 仍先叫辉哥

## 已验证流程（Xander）

### 1. 聊天里先口头约到店

对齐匹配后，用口语约具体时间，例如演示原话方向：

> 可以嘛，挺好的，要不约个时间来店里聊聊。后天周一，下午一点半。你看怎样

要点：说清 **来店里** + **星期/时间**；等对方表态。

### 2. 发系统「面试邀请」

聊天底栏点 **约面试**（发出成功后，系统气泡出现 **「发送了面试邀请」**；底栏按钮会变成 **查看面试**，电话侧可能变成 **查看电话**）。

约面试弹窗里的时间/地点等字段：**演示未完整截到表单填写过程** → 以辉哥当场填写为准；不要用猜的地址。填完发出后截图确认仍是同一候选人。

### 3. 对方接受后收口

- 系统气泡：**「接受了面试邀请」**
- 对方会再确认时间（演示：`那就周一下午见，板板`）
- 回一句确认即可（演示：`好的，晚安`）
- 需要核对详情时点 **查看面试**

### 4. 立刻更新索引

候选人卡片 + `INDEX.md`：状态改为 `已约面`，写明到店时间、是否已接受系统邀请。

## 预期画面

| 步骤 | 预期 |
|---|---|
| 口头约面已发 | 右侧气泡含「来店里」+ 具体时间；顶栏姓名正确 |
| 系统邀请已发 | 出现「发送了面试邀请」；底栏有「查看面试」 |
| 对方已接受 | 出现「接受了面试邀请」；对方确认到店时间 |

## 失败模式

- 点到「不合适」→ 立刻停，汇报辉哥
- 「意向沟通」挡点击 → quit+reopen（见 boss-zhipin-click）
- 顶栏姓名 ≠ 目标 → 不发（boss-send-guard）
- Electron 点不中约面试 → 请辉哥点，勿连点

## 不要做

- 未经辉哥批准代点「约面试」
- 编造门店地址、面试时长、联系人
- 约面后擅自换微信/打电话
- 把云电脑当 Boss 操作面
