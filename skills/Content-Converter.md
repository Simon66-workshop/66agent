# Skill 03 · Content Converter

只有 P0，或 **V≥80** 的 P1 进入。V 70–79 不进本 skill。每次最多 3 张 Content Card。不要自动发布。发布键仍由辉哥按。

成稿由宿主模型写。第三层若用过 Jev，卡片或日报注明「引用 `skills/jev-x-layer3.md` 留档」；本 skill 的写作步骤写「宿主模型」。没有调用就写「本任务成稿未调用 Jev」。不在这里重问五题，不把 Jev 用于传输层。

## 每张卡
事件、核心事实、为什么重要、别人通常怎么看、我的不同观点、最强反证、仍然不知道什么、适合形式（X/小红书/抖音/长文）、标题、开头钩子、核心观点、证据、案例、我的实践、结论、商业关联、是否值得真实测试、下一步动作。

## 门禁
不允许只转述新闻。必须追：新功能 → 旧问题 → Codex/Cursor/Claude Code/Grok Build 有没有 → 真实项目差异 → 自己的实验 → 判断。

日报额外必须给：最值得实践的技巧、最值得研究的商业机会、最值得制作的内容、最重要的反证、一个 Unknown Unknown、今天应该忽略什么。
日报发到 simonwu.chi@gmail.com。

## 必过顺序（MUST）

禁止新闻复述。每张卡必须按这个顺序写完，缺一步不出卡：

1. 事实
2. 反证
3. 工具比较
4. 实践
5. 观点
