# Boss 直聘：看人 → 回复（跟学固化）

只在 **MacBook Pro** 已登录的 BOSS直聘上跑。先 [locate-machine-probe](sand-workflow:locate-machine-probe)（角色=Pro），点选操作跟 [boss-zhipin-click](sand-workflow:boss-zhipin-click)。剪辑岗话术细节跟 [boss-editor-chat](sand-workflow:boss-editor-chat)。**没演示过的步骤不要编。**

## 前置

- App：`BOSS直聘` 已开、已登录（不要往云电脑登）
- 入口：左侧 **消息**（红标可有可无）
- 优先清 **新招呼**；职位筛不清时先选 **全部职位** 再进新招呼

## 单人循环（演示顺序）

1. 在中间列表点开候选人（预期：右侧出聊天 + 顶栏姓名/活跃；未选中时右侧是「未选中联系人」占位）
2. **先读再回**：顶栏年龄/经验/学历、工作经历摘要、期望城市/薪资、整段聊天（已问过的不重复）
3. 需要简历时优先点顶栏 **在线简历** / **附件简历**（有同意弹窗先同意）；点选坐标见 boss-zhipin-click
4. 决定话术：
   - 有现成口径 → 点输入区上方 **常**（常用语）→ 选中对应条 → 点条旁 **发送**
   - 要定制 → 在输入框手打 → 点绿色 **发送**
5. 发出后截图核对气泡为己方消息且状态「送达/已读」；再处理下一位
6. 列表点飘 / 弹「意向沟通」：按 boss-zhipin-click（关不掉就 quit+reopen），勿烦辉哥

## 演示里实际发出的话术（可复用）

| 场景 | 话术 | 备注 |
|---|---|---|
| 改装岗开场（学徒说明，常用语） | 我们这边汽改装学徒，要学会仓务管理，汽车改装（外观，内饰，音响，性能动力，悬挂），还有一些场景整理。 | 演示对「李生」发出 |
| 改装岗开场（要简历+兴趣） | 您好，方便看看你的简历吗？另外您对这个汽车改装行业喜欢吗？ | 连续对张森义/陈俊杰/刘桂平/温天发出；可手打也可进常用语 |
| 剪辑岗拒居家兼职 | 不行呢，我们需要到岗的 | 演示对「邱女士」；对方问居家/按条数时用 |

剪辑岗 AE/口播/抖音 `66_Workshop` 等更细口径见 boss-editor-chat（本次演示未再走那条）。

## 栏位与按钮（稳定标签，少靠坐标）

- 列表顶 Tab：全部 / **新招呼** / 沟通中 / 已约面
- 聊天底栏快捷：求简历、换电话、换微信、约面试；右侧 **不合适**
- 输入区图标：表情、**常**（常用语）、地址、附件

## 筛选直觉（演示可见，非编造）

- 先看岗位是否对口（改装技术工程师 vs 短视频剪辑等）
- 看经历摘要是否相关；改装岗可先要简历并问行业兴趣再深聊
- 明确只要居家兼职/按条 → 用到岗拒句；是否点「不合适」演示未做，默认**先回消息**，点「不合适」前问辉哥

## 停点（必须先停）

- **换微信 / 换电话 / 约面试 / 录用 / 点不合适** → 先叫辉哥
- **薪资/作息/社保具体数字**：只用辉哥原话或已确认常用语；无原话不编（演示未核定新数字）
- 付款、购买权益、授权、2FA → 交给辉哥

## 失败模式

- 列表点不到人 / 点错人：截图核对标题；改用键盘 Down+Return 或搜姓名
- 常用语面板挡住：再点 **常** 关闭或 Esc，确认输入框可见再发
- 意向沟通/购买弹窗：X 打不中就 quit+reopen BOSS直聘
- 机器串台：探针指纹不是 Pro 就停手

## 不要做

- 往助手云电脑登录 Boss
- 盲坐标进会话、不截图就外发
- 补演示里没走过的长流程（批量同意微信、自动点不合适等）
