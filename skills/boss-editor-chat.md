# Boss 剪辑岗代聊话术（从真实聊天蒸馏）

用在 Boss 直聘「短视频剪辑 / 新媒体摄影师」等相关岗：先 [locate-machine-probe](sand-workflow:locate-machine-probe) 锁定 Pro，再按 [boss-zhipin-click](sand-workflow:boss-zhipin-click) 操作。口吻跟辉哥真实聊天走，不公文。

## 业务怎么说（已验证原话方向）

- 内容两块：**口播类个人 IP** + **专门做展示的账号**（改装/产品案例展示）
- 技能偏好：**会 AE 更好**（特效、包装、酷炫运镜）
- 风格对标：直接发抖音 **`66_Workshop`**，让对方自己看，少空讲「有网感」

## 追问模板（可自行发出）

- 对方提 AE/包装：「那很酷炫的运镜效果你也会做咯？」
- 说明业务：「现在口播类的IP比较多，还有一个账号专门做展示的，会AE的更好」
- 给参考：「抖音：66_Workshop」
- 要材料：「方便发简历和作品看看」「看看您简历哈」（已要过的不重复）
- 轻开场仍可用：「你好啊，可以聊一聊～」/「铁子，聊一会哈」

## 筛选信号

- **加分**：AE 特效/包装、变速运镜、能看懂对标账号并聊到具体成片问题
- **可继续**：自称主要后期、没拍过前期——先看作品，不立刻否
- **低配**：无成片、经历完全无关、只要学徒且岗位要熟手 → 软拒
- 待遇/作息：**无辉哥原话不编**；确认后再答

## 软拒（已定口径可发）

- 「你好，看了，不太合适，不好意思」
- 「好的哈，我们这边更看成片作品（改装/口播）。你暂时没有的话，可能先不太合适，谢谢你～」

## 重大决定

换微信 / 约面 / 录用 → 先叫辉哥。
