## 实际走过的步骤

1. 上传或指定真车图（凯迪拉克 XT6 黑武士：黑车身、黑轮毂、红卡钳）。
2. 用项目里的「电影海报 skill」出图，不要另起风格。
3. 提示词按这个骨架，只换车型词：

```
创建图片
去掉车牌和背景商业logo，用我们的电影海报skill，设计6张海报风的图，比例3：4，凯迪拉克XT6黑武士，封面描述词可以设计得更有设计师范
```

4. 出图后立刻加约束（他后来补过，模型常忽略）：
   - 一次只出 **1 张** 独立 3:4 竖版，禁止六宫格 / 拼贴 / 海报展
   - 签名用片尾字幕体：`FOSHAN · 66 WORKSHOP`
   - 车要大，车间/工业暗调，冷色，红卡钳保留
   - 禁廉价赛博、假 Logo、车辆比例错误、车牌、别人店招
5. 六宫格只能当选图板。定稿封面从格子里裁一张，或让它按第 4 步重出单张。
