# HR 多维评分（候选人 Scorecard）

把「感觉还可以」收成**同岗可比较**的分数与建议。蒸馏自：结构化面试/胜任力评分（BARS）、面试 scorecard 实践（4–6 维 + 证据 + 总评）、国内招聘评分表闭环（画像→证据→独立评分→建议）。配合 [boss-candidate-index](sand-workflow:boss-candidate-index)、[boss-editor-chat](sand-workflow:boss-editor-chat)、[hr-professional-reply](sand-workflow:hr-professional-reply)、[boss-message-screen](sand-workflow:boss-message-screen)。

## 何时用

- 看过简历/作品，或聊完一轮，要给辉哥**评价**
- 比较多名候选人、决定推进/Hold/软拒
- 辉哥说「打分」「综评」「适不合适」

## 硬规则

1. **先定岗再评分**：写明沟通岗（如短视频剪辑 / 改装学徒 / 新媒体摄影）。换岗重评。
2. **每分必有证据**：简历句、作品文件名/观感、聊天原话。无证据 → 标 `未评`，**禁止脑补**。
3. **缺证不硬抬**：未聊离职/规划就别把「稳定性」打高。
4. **一票否决先写**：居家 vs 到岗、城市不符、无作品硬岗、造假嫌疑等 → 可直接软拒，其余维度可略写。
5. **结论写进候选人卡片** `people/<slug>.md` 的「评分」节，并改 `INDEX.md` 匹配列。
6. 不问婚育等歧视项；待遇数字无辉哥原话不评「性价比高低」的绝对数。

## 默认量表（1–5，行为锚定）

| 分 | 含义 |
|---|---|
| 5 | 强证据，明显超岗所需 |
| 4 | 扎实达标，可放心推进深聊 |
| 3 | 基本达标，有缺口但可补/可培养 |
| 2 | 偏弱，缺口影响上岗 |
| 1 | 明显不符或高风险 |
| 未评 | 本轮无材料，不计入加权（分母剔除） |

## 默认六维（短视频剪辑 / 汽车展示内容岗）

权重可按岗微调；下列为**剪辑岗默认**（总分按已评维加权到 100）。

| 维 | 权重 | 看什么 | 5 分锚 | 1–2 分锚 |
|---|---|---|---|---|
| D1 硬条件匹配 | 15 | 城市、到岗、薪资带是否可谈、沟通岗 vs 求职意向 | 广州/佛山到岗、意向与岗接近 | 坚持居家/异地不可协调 |
| D2 作品与手艺 | 25 | 成片网感、运镜/包装/调色、AE、汽车/口播相关 | 多条对口成片，AE/节奏明显 | 无成片或完全无关 |
| D3 经历与结果 | 15 | 相关司龄、职责深度、播放/交付结果（有数字更好） | 独立扛过对口项目且有结果 | 经历注水或完全不对口 |
| D4 方向与动机 | 15 | 拍 vs 剪意愿、是否接受「剪辑为主」、对业务线兴趣 | 清晰接受岗要求并说得出为什么 | 只想拍/方向漂、与岗冲突 |
| D5 稳定性 | 15 | 跳槽频率、离职原因合理性、近一两年规划 | 离职说得通+规划与岗同向 | 闪离/说不清/规划与岗相反 |
| D6 沟通与协作感 | 15 | 回复质量、材料完整度、是否好推进 | 响应快、材料齐、问答具体 | 已读不回、材料糊、答非所问 |

改装技术/学徒岗：把 D2 改成「动手与行业兴趣」，D3 侧重仓务/改装接触；权重仍六维合计 100。

## 综合分

```
综合分 = Σ(维得分 × 维权重) / Σ(已评维权重) × 100
```

只对「已评」维加权。另给**信心**：高 / 中 / 低（看缺证多少）。

### 建议档（给辉哥，非自动录用）

| 综合分（大致） | 建议 |
|---|---|
| ≥80 且无否决 | **推进**（可深度聊 / 叫辉哥看是否换微信） |
| 65–79 | **可继续**（补 1–2 个关键问题后再评） |
| 50–64 | **Hold / 备选** |
| <50 或一票否决 | **软拒**（用已定话术） |

## 输出模板（必须按此交辉哥）

```markdown
### 评分：{姓名} — {沟通岗}
- 日期：
- 综合分：{n}/100（信心：高/中/低）
- 建议：推进 / 可继续 / Hold / 软拒
- 一句话：

| 维 | 权重 | 分 | 证据（短） | 缺口 |
|---|---|---|---|---|
| D1 硬条件 | 15 | | | |
| D2 作品手艺 | 25 | | | |
| D3 经历结果 | 15 | | | |
| D4 方向动机 | 15 | | | |
| D5 稳定性 | 15 | | | |
| D6 沟通协作 | 15 | | | |

- 优势（≤3）：
- 风险（≤3）：
- 下一问 / 下一动作：
- 否决项：无 / 有（写明）
```

## 操作步骤

1. 读 [boss-candidate-index](sand-workflow:boss-candidate-index) 卡片 + 聊天/简历/作品要点  
2. 标一票否决；有则建议软拒并停深聊  
3. 逐维打分；缺证写 `未评`  
4. 算综合分 + 建议档 + 信心  
5. 用上面模板发给辉哥；写入 `people/<slug>.md`「评分」并更新 INDEX  
6. 建议「推进」且涉及换微信/约面 → **仍先叫辉哥**

## 剪辑岗快速对照（业务口径）

- 加分：AE/包装运镜、口播 IP + 改装/产品展示成片、抖音对标能聊到具体片  
- 可继续：主后期少拍摄 — 先看成片  
- 减分：无成片、只要学徒但岗要熟手、不接受剪辑为主  

## 不要做

- 无作品却给 D2 高分；未问离职就给 D5 高分  
- 用年龄/学历刻板印象代替证据  
- 把综合分当成自动录用；重大决定仍听辉哥
