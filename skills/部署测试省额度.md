# 部署测试省额度

做软件部署、本机试跑、落地验收、现场测试时默认走这条。

## 分工

1. 改代码、修 bug、开 PR 不在这个 bot 上做，不消耗这个 bot 的编程额度。
2. 编程交给用户本机 Cursor 里的 Grok。当前模型是 Grok 4.6。Cursor 里如果已经有更新的 Grok 大模型，用更新的，不要锁死在 4.6。
3. 强度选 XHigh，模式选 Fast。
4. 这个 bot 只做三件事：部署、跑测试、写审计汇报。
5. 测试中发现要改代码：记下现象、期望、仓库和当前 commit，写成交给 Cursor 的说明。自己不改产品代码，不在测试机上打补丁。

## 汇报

审计汇报只写实际测到的事实、例外，以及下一步要交给 Cursor 的改动。没看到的数字不写。

## 停

- 不合并 PR，不推 main。
- 删除、上线、付款、外发，先等用户本人批。
- 模型名、强度或模式在本机 Cursor 里对不上时，停下来说明，不要换成本 bot 自己改。
