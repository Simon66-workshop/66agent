# Skill：代码项目与工作长任务默认协作模式

**何时用**：GitHub 仓库开发/修复/测试/生产验证/独立审计，或 ChatGPT Work 长任务交接。

**做什么**：按 `shared/代码项目与工作长任务默认协作模式.md` 执行「仓库即交接面」闭环。

**硬检查**：
1. 阶段材料是否已由执行者自行 commit + push？
2. 是否给出 commit / 证据树 / README / 判决的 **permalink**（非裸分支）？
3. 是否外读复核 SHA（非仅 push 成功）？
4. 独立审计是否按证据重判（不继承自报）？
5. 历史回执是否保留未覆盖？
6. 是否在逼辉哥当搬运工？（默认禁止）

**不要做**：把测试绿 / 工程 PASS / 历史收据当成生产验收；未独立 PASS 就推进下一阶段。
