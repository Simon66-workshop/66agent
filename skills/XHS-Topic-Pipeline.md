# 小红书选题流水线 · v0.1

给人/Agent 的一次手动跑通。不启动每日 routine、影子模式、自动发布。

本地 skill 镜像目录是 `/Volumes/2T扩展盘/Agent文件/skills`。本文件只存在于 Git 仓库时，合入后由辉哥本机按双写协议同步；**不要**在够不着的机器上编造一份已写好的副本。

## 层

| 顺序 | 文件 | 做什么 | 不做什么 |
|---|---|---|---|
| 0 | `XHS-Radar-Slots.md` | 5 个默认搜索槽 | 不扫描、不改 X Radar |
| 1 | `XHS-Radar-Scout.md` | ≤20 信号卡，等级 L0 | 不打分、不拆解 |
| 2 | 确定性规则 | 预算、去重、排除词、访问态、时间 | 不叫 Jev |
| 3 | `XHS-Jev-Filter.md` | 五题过滤；硬丢的不打开 | 不算 X 热度 H；不写传输回执；通过 ≠ 可拆解 |
| 4 | 详情预读（Scout 记下的链接） | Jev 存活候选最多开 **5** 条到 L1 | 不拆解、不播放；不编 `xsec_token`；裸 `/explore/{id}` 失败记 BLOCKED |
| 5 | `XHS-Evidence-Judge.md` | 对已开详情打分；L0 不 advance | 不写正文；不得先打分再决定开详情 |
| 6 | `XHS-Deconstruct.md` | 只拆 P0 / 高 P1 | 无回执不声称看过视频 |
| 7 | `XHS-Content-Converter.md` | ≤3 张可粘贴提纲 | 不发布 |
| 可选 | `Notion商业版日更交接.md` | 报告页 + 选题库候选 | 不代点发布；ID 不进 skill |

## 预算（可被任务收紧，不可放宽）

| 项 | 上限 |
|---|---|
| 槽 | 5（当次可少用） |
| 发现候选 | 20 |
| 每槽笔记 | 4 |
| Jev 存活后、打分前打开详情 | 5（只为升到 L1；不是拆解配额） |
| 拆解 | 3 |
| 视频播放（L3） | 1 |
| 单条可见评论 | 8 |
| 交给人的 P0 / P1 | 2 / 3（上海日） |
| 选题卡 | 3 |
| 软题宿主复核 | 10（上海日） |
| 同一搜索词频控重试 | 2（见下节；不因此放宽发现候选 20） |

时间窗：优先近 30 天，90 天内可进池。相对时间未核绝对日期 = UNKNOWN，不算已核窗内。

频控不占「放宽预算」。撞墙后的重试只换页面，不追加候选上限，也不把失败页算成已打开的详情配额之外的第 6 条。

## 频控（试跑已验）

页面出现 **Requests too frequent**、**Security Verification** 或验证码墙时，按顺序做，不可打乱：

1. 立刻停止点按。
2. 冷却 **60 秒**。
3. **关掉当前页面/标签**。
4. 再开一条新的搜索 URL，或（若人在详情步）一条新的详情 URL。
5. **同一搜索词**最多这样重试 **2** 次。仍是墙：该词 `BLOCKED`，换槽里的下一词。不换词连打。
6. **禁止**手动过验证码、登录绕过、绕风控。人不代点验证码，Agent 也不代点。

频控 `BLOCKED` 的词和卡：不打开详情，不问 Jev，不打分。原因写进运行记录（看见的原文提示），不写 cookie。

## Jev 放哪

```text
搜索列表（L0，保留 search_result?xsec_token=）
  → 确定性丢弃（预算/去重/排除词/登录墙/时间）
  → Jev 五题（或 JEV_NOT_RUN / HOST）
  → 存活候选打开 ≤5 详情，升到 L1
  → 主模型打分 / advance（L0 不得 P0，不得高 P1）
  → 主模型只拆 P0 / 高 P1，再写提纲
```

分类、过滤、路由在规则之后用 Jev。拆解、反证展开、提纲用主模型。  
是否打开页面、数字是否看见、Notion 是否写上：看工具返回，不问 Jev。

无 key：不发 HTTP，运行记录写 `Jev: NOT_RUN`。需要过硬门禁时由主模型按同题作答并标 `source=HOST`，不得假装 `source=Jev`。

## 输出

一次跑完至少留下：

1. 信号卡列表（含 BLOCKED）
2. `Jev: RUN` 或 `Jev: NOT_RUN`（HOST 题单独标）
3. Judge 表
4. 拆解卡（若有 P0/高 P1 且打开成功）
5. 0–3 张选题卡
6. 访问失败时的 BLOCKED / FAILED 原因（验证码、登录、限流、页面空）

指标没看见写「未找到」。禁止把缺失写成 0。

零结果是合法收口：写 `ZERO_IN_BUDGET`，不要放宽预算再搜一轮凑数。

## Notion 交接（可选，人要求时）

按 `skills/Notion商业版日更交接.md`：

- 只把已出卡、且有方法有数字的条目写入选题库，状态用「候选」
- 报告页区分 FACT / INFERENCE / POV / UNKNOWN（POV 只来自 Converter）
- 账号、数据库 ID 放 routine 或记忆，不写进 skill
- MCP 不可用：在运行记录写 `NOTION_SKIPPED`，不要编验证通过
- **不代点发布**

## 失败

| 情况 | 写法 |
|---|---|
| Requests too frequent / Security Verification / 验证码墙 | 按「频控」：停点、冷却 60 秒、关页、新开 URL；同一词最多 2 次；仍墙则该词 `BLOCKED`，换下一词。禁止过验证码 |
| 页面打不开、超时、裸 explore「页面不见了」 | `BLOCKED` 或 `FAILED`，不编摘录；改用带 token 的 search_result，没有 token 就停 |
| 结果不确定、可能已看过 | `UNKNOWN`，先查当次笔记再决定开不开 |
| 第三方数字无交叉 | 不得标 FACT |
| 视频无播放回执 | 证据 ≤L2，禁止「已看完」 |
| 连续需要自动放行 | v0.1 没有自动放行。停，交给人 |

## 和 Self-Optimizer 的边界

v0.1 不跑每周自优化，不改 `66-Intelligence-Ledger.md`（那是 X 账本）。  
以后若要优化，只基于外部结果（人是否采用、是否实拍、是否带来到店），不基于没看见的点赞。槽词、排除词、80 分门槛、Jev 题干都是黄区。发布仍是红区，必须人按。

## 手动跑一次

1. 读本文件、槽、两份数据源清单、种草方法论。不登录、不建 routine。
2. Scout：公开搜索为主，官方后台仅在人已经打开时只读。撞上频控就走「频控」六步，不要继续点。
3. 用排除词和预算删卡。
4. 有 `TYPESAFE_API_KEY` 才按 `XHS-Jev-Filter.md` 调 Jev；否则 `JEV_NOT_RUN`。硬丢的不打开。
5. 用信号卡里的 `search_result/{id}?xsec_token=` 给存活候选开详情，最多 5 条，升到 L1。没有 token 不编。裸 explore 打不开就记 BLOCKED。
6. Judge。L0 不 advance。只把 P0 / 高 P1 送去拆解。
7. 拆解。视频默认不播。沿用上一步的详情链接。
8. Converter，最多 3 张，封面标题 ≤20 字。
9. 人要求再做 Notion 交接。
10. 回报：候选数、丢弃原因、Jev 状态、打开详情数、卡片数、BLOCKED。不写「已发布」。

## 验收

- [ ] 层表顺序被遵守：Jev 之后才开 ≤5 详情，然后才打分；没有跳过规则直接打分
- [ ] 预算没有放宽；频控重试 ≤2，且没有手过验证码
- [ ] 频控 BLOCKED 的词没有打开详情、没有问 Jev
- [ ] Jev 状态诚实
- [ ] 选题卡 ≤3，且没有发布
- [ ] 旧的小红书清单文件未被替换
- [ ] 运行记录里没有 cookie、key、账号密码
