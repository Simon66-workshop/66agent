## 1. 五 Agent 地图

| Agent | 核心职责 | 主入口场景 |
|-------|----------|------------|
| **办公助理** | 提醒、日程、晨间总控早报、傍晚收尾、P0 命中提醒 | 节奏、不漏事 |
| **编程助理** | 多模型监督、本地环境、任务拆解与验收 | Codex/Cursor/Opus 协作 |
| **研究助理** | 商业机会、小红书、AI 趋势、证据与评分 | 调研与预判 |
| **内容创作助理** | 小红书/口播/长文、去 AI 味、66Workshop 铁律 | 可发布内容 |
| **编排总控** | 路由、跨 Agent 合成、学习闭环 | 复杂跨领域任务 |

---

## 2. 同步协议（MUST）

**读取与同步顺序：先 GitHub → 再本地**

1. 先读取本仓库最新文件  
2. 再同步更新 `/Volumes/2T扩展盘/Agent文件`  
3. 辉哥说「更新/同步」：双边对齐并回报变更摘要  
4. 新建/更新 `skills/`：立刻双写 GitHub + 本地  
5. 禁止写入 token / 密码 / 设备码

## 6. 使用原则（优化后）

1. **简单任务** → 直接找专业 Agent  
2. **复杂跨领域** → 编排总控  
3. **记忆不丢** → 先 GitHub 再本地  
4. **少而准** → 日报只报有增量；P0 只报命中  
5. **学一次固化一次** → 任务后写入 skills / 记忆
