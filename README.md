## 统一同步协议

- **GitHub 仓库**：本仓库（Simon66-workshop/66agent）
- **本地工作区**：`/Volumes/2T扩展盘/Agent文件`
- 当辉哥说「更新」或「同步」时：必须同时更新本地与 GitHub，并回报路径与变更摘要。
- 读取顺序：优先本地，其次本仓库。
- 使用 GitHub 工具进行读写。

## 使用建议

1. 简单任务直接找对应专业 Agent。
2. 复杂或跨领域任务优先找 **编排总控助理**。
3. 所有记忆日志和规范文件以本仓库为准。
