# 办公助理 · 全员同步广播模板

**用法**: 辉哥只对「办公助理」发一条主指令；办公助理自己更新后，输出可转发到 66GrokBot Group 的全员通知，避免逐个 Bot 发消息。

**限制说明**: Grok 各 Custom Bot 无法互相私信；真正「通知其他 Bot」= 办公助理生成标准广播文 → 辉哥粘贴到 Group 一次，或分别粘贴。

## 办公助理应输出的 Group 广播文结构

1. 自己已完成：GitHub → 本地同步摘要
2. 本次全员必须加载的新文件列表
3. 分角色自检要求（研究/编程/总控内容）
4. 研究→内容交接模板已生效，要求研究收尾必须带交接块
5. 请各 Bot 回复「已同步」+ 身份一句话
