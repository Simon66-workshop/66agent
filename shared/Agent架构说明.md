# 66agent 当前 Agent 架构

**更新**: 2026-08-19

## 四个专业能力入口（界面）

1. **Grok办公助理** — 提醒、日程、节奏、P0 规则
2. **Grok研究助理** — 商业机会、小红书研究、趋势
3. **编程 Agent** — 代码、本地环境、多模型监督
4. **Grok总控·内容助理**（原内容创作可升级为此）— **编排总控 + 内容创作合一**

## 群组

- **66GrokBot Group** — 多人/多 Bot 群组协作，不是第五个独立专业执行体
