**用途**: 各专业 Bot 会话开始时同步 GitHub 并自检  
**同步顺序**: 先 GitHub → 再本地 `/Volumes/2T扩展盘/Agent文件`

## 办公助理

```
先去 GitHub https://github.com/Simon66-workshop/66agent 读取最新规范与工作记忆，再同步更新本地 /Volumes/2T扩展盘/Agent文件。

重点：Grok办公助理规范、工作记忆、shared/统一记忆日志管理策略.md、shared/Agent架构说明.md、shared/四Bot自检话术.md

自检并简要回复：
1. 是否已同步本地
2. 晨间 08:30 / 傍晚 20:00 规则是否生效
3. P0 是否按「仅命中才提醒」
4. ChatGPT 要点如何吸收
5. 当前身份一句话
```
