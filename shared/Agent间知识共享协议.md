# Agent 间知识共享协议

**版本**: 1.0  
**创建日期**: 2026-08-18  
**适用对象**: 辉哥全部 Grok Agent 套件  
**中央仓库**: https://github.com/Simon66-workshop/66agent  
**本地工作区**: /Volumes/2T扩展盘/Agent文件

---

## 1. 核心原则

1. **单一真实来源**：所有可共享知识最终落盘到中央仓库（规范文件、工作记忆日志、skills/）。
2. **读写分离**：
   - 每个 Agent 只**写入**自己的工作记忆日志。
   - 可**读取**其他 Agent 的公开日志摘要、skills/ 文件、以及编排总控维护的全局状态。
3. **最小必要传递**：跨 Agent 传递上下文时，只传任务所需的最小干净信息，避免污染。
4. **可追溯**：任何共享的知识必须能追溯到来源 Agent 与时间。
5. **冲突处理**：出现矛盾时，由编排总控收集双方证据，提交辉哥裁决，再统一写入。

---

## 2. 知识分类与共享权限

| 知识类型 | 存放位置 | 谁可写 | 谁可读 | 共享方式 |
|----------|----------|--------|--------|----------|
| 个人偏好 / 风格 | 各 Agent 工作记忆日志 + skills/辉哥业务背景.md | 对应 Agent | 全部 | 直接读取文件 |
| 可复用技能 / SOP | skills/ 目录 | 专业 Agent 或编排总控 | 全部 | 读取 skills/ 文件 |
| 任务过程洞察 | 各 Agent 工作记忆日志 | 仅自己 | 编排总控 + 相关 Agent | 编排总控摘要后共享 |
| 跨 Agent 项目状态 | 编排总控工作记忆日志 | 仅编排总控 | 全部 | 编排总控主动告知 |
| 最终决策 / 裁决 | 相关日志 + skills/ | 编排总控（经辉哥确认） | 全部 | 写入后通知 |

---

## 3. 共享流程

### 3.1 主动共享（推荐）
1. 专业 Agent 在任务中产生有价值的新知识。
2. 通过学习闭环蒸馏成简洁条目。
3. 写入自己的工作记忆日志，或提升为 skills/ 文件。
4. 若对其他 Agent 有用，通知编排总控。
5. 编排总控决定是否写入全局状态或通知相关 Agent。

### 3.2 被动读取
- 任何 Agent 在需要时，可直接用工具读取：
  - `skills/` 下的文件
  - 其他 Agent 的工作记忆日志（只读摘要）
  - 编排总控的全局记忆
- 读取后应在自己的日志中记录「参考了哪些外部知识」。

### 3.3 编排总控的协调职责
- 维护「全局知识索引」简表（哪些技能可用、最近重要洞察）。
- 在跨 Agent 任务中，主动把必要知识作为精简上下文传递。
- 发现知识冲突时，暂停并提交辉哥。

---

## 4. 禁止事项（NEVER）

- 禁止直接修改其他 Agent 的工作记忆日志。
- 禁止把未经验证的临时对话内容直接当成共享知识写入 skills/。
- 禁止在跨 Agent 传递时附带大量无关历史。
- 禁止绕过编排总控，私自建立「隐式共享渠道」。

---

## 5. 冲突与裁决流程

1. 发现冲突 → 相关 Agent 报告给编排总控。
2. 编排总控收集双方证据与来源。
3. 提交辉哥裁决。
4. 裁决结果写入相关日志 + 必要时更新 skills/。
5. 通知所有相关 Agent。

---

## 6. 与学习闭环的关系

学习闭环是知识产生的主要入口。  
本协议规定知识产生后如何被安全、有序地共享与复用。

两者结合，形成「产生 → 蒸馏 → 共享 → 复用 → 再进化」的完整循环。

---

## 7. 初始化与维护

- 本协议文件路径：`shared/Agent间知识共享协议.md`
- 各 Agent 规范文件应引用本协议。
- 重大变更需辉哥确认后更新，并同步到仓库。

---
