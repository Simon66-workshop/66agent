# 研究 → 内容 固定交接模板

**用途**: 研究助理收尾与总控·内容成稿的标准接口  
**更新**: 2026-08-21

---

## A. 你给研究助理（要结论时）

```
按商业机会 SOP 研究：【主题】

输出只要：
1. 关键结论（3–5条，附置信度）
2. 事实与证据（来源+日期）
3. 第一性原理要点
4. 机会评分
5. 可行动建议（尤其能否做成小红书/口播）

不要长文。做完用【交接给总控·内容】格式结尾。
```

---

## B. 研究助理结尾（标准交接块）

```
【交接给总控·内容】
主题：
一句话结论：
适合内容的角度（1–2个）：
关键事实（可引用）：
避免踩的坑/不确定点：
建议体裁：小红书图文 / 口播 / 两者
```

---

## C. 你给总控·内容（成稿时）

```
下面是研究交接，请进入内容模式，不要再做深度调研。

【研究交接】
（粘贴研究助理的交接块）

请输出：
1. 是否值得做（值得 / 暂无强推）
2. 若值得：选 1 个主角度
3. 封面短标题（≤15字）+ 文案标题（约20字）
4. 钩子（开头3秒）
5. 大纲（小红书或口播结构）
6. 去 AI 味自检要点

先给大纲，我确认后再写全文。
```

---

## D. 一条龙（已有结论时直接丢总控·内容）

```
内容模式，不调研。基于以下结论做小红书/口播：

结论：
关键事实：
目标读者：
平台：小红书

输出：是否值得做 → 主角度 → 标题 → 钩子 → 大纲。
确认前不写全文。
```
