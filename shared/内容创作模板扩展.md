# 内容创作模板扩展

供 Grok内容创作助理使用，可直接引用。

---

## 1. X 长帖 / 线程模板

**结构**：
1. 钩子帖（结论或痛点，引发点击）
2. 展开 3-5 条（每条一个清晰重点）
3. 案例 / 数据支撑
4. 总结 + 明确 CTA（关注 / 评论 / 私信）

**风格要点**：短句、节奏变化、有判断、避免堆砌。

---

## 2. 技术博客模板（结论先行）

```
# 标题（结论或价值明确）

## 一句话结论

## 问题背景
为什么这个话题重要

## 核心原理 / 方案

## 落地步骤（可操作）

## 注意事项与常见坑

## 总结 + 下一步建议
```

---

## 3. 专业邮件模板

**主题**：清晰具体，避免模糊

**正文结构**：
1. 开头一句话说明目的
2. 正文分点（1. 2. 3.）
3. 明确下一步行动或请求
4. 礼貌收尾

语气：专业 + 有温度，不官僚。

---

## 4. 短视频分镜脚本模板（口播向）

```
【时长目标】45-90 秒
【核心信息】一句话

0-3s：强钩子画面 + 口播
3-20s：痛点 / 背景
20-60s：核心方法 / 案例（分 2-3 个点）
结尾：总结 + 行动引导

【画面提示】
【口播正文】（标注停顿）
【字幕重点】
```

---

## 5. 小红书种草加强版

```
【封面短标题】（20字内，强结果或痛点）

正文标题

开头钩子（痛点 / 好奇 / 结果）

主干：具体方法 + 真实细节 + 对比 / 案例

真实感受（有毛刺更好）

结尾：总结 + 互动引导（评论 / 收藏）
```

---

## 6. 去 AI 味检查清单（强制）

- 避免「首先、其次、最后、总的来说、值得注意的是」
- 句子长度有变化
- 多用具体细节与个人观察
- 减少绝对化表述
- 保留适度真实感与判断

使用时优先主干先行，价值明确。
